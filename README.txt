JINKO VEGAS PREMIUM - Android Studio source project (v1.1)

FUNCTIONS VERIFIED AT SOURCE LEVEL
- Dashboard and local collection progress storage
- Real Android-installed game version check (uses PackageManager)
- Launches the installed Gangstar Vegas application if present
- Full existing Black & Purple UI and © JINKO notice preserved

LIMITATIONS
This is NOT a cheat. It cannot change Gangstar Vegas money, gems, weapon or car unlock flags. Those features were not verified and are not included. Native game detection requires Android; in a web browser the buttons explain the limitation.

BUILD
1. Open this folder in Android Studio.
2. Let Gradle sync (Android Gradle Plugin 8.6.1, compile SDK 35).
3. Build > Build APK(s).
4. Install app/build/outputs/apk/debug/app-debug.apk on Android.

This environment has no Android SDK, so the source is NOT compiled and the APK has NOT been tested on a phone.
